\section{Постановка задачи}

Требуется разработать консольную программу, позволяющую выполнять преобразование
чисел из десятичной системы счисления в двоичную и обратно. Для вещественных чисел
необходимо реализовать кодирование и декодирование формата bfloat16, воспроизводя
основные этапы представления чисел с плавающей точкой без применения готовых
библиотечных средств упаковки bfloat16.

Программа должна предоставлять пользователю выбор направления преобразования,
показывать полученное 16-битное представление и отдельно отображать знак,
смещённую экспоненту и мантиссу числа.

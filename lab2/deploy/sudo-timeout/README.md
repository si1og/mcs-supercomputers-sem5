# Sudo: авторизация на 60 минут

Файл `90-lab-sudo-timeout` устанавливается на server01, server02, server03 и client в `/etc/sudoers.d/90-lab-sudo-timeout` с владельцем root и правами 0440.

```sudoers
Defaults:ilyasemenov timestamp_timeout=60
```

После успешной авторизации команды sudo в том же терминале используют кэш в течение 60 минут. Сохраняется штатная область действия кэша; новая SSH-сессия может запросить пароль снова. Настройка не выдаёт дополнительных прав и не включает NOPASSWD.

`timestamp_timeout` не меняет срок ожидания ввода в приглашении пароля (`passwd_timeout`). Перезапуск службы для применения не нужен.

Скопировать файлы на узел и выполнить:

```bash
sudo bash ./install.sh
```

Установщик проверяет текущую конфигурацию, наличие include каталога sudoers.d и новый файл через visudo. Отличающийся существующий файл не перезаписывает.

Проверка:

```bash
sudo visudo -cf /usr/etc/sudoers
sudo -l
```

В списке Defaults должно присутствовать `timestamp_timeout=60`.

В этом openSUSE основной пакетный файл расположен в `/usr/etc/sudoers` и включает `/etc/sudoers.d`. Явное `-f` проверяет синтаксис, не отклоняя штатные пакетные файлы с правами 0444. Наш файл устанавливается с правами 0440.

Для немедленного сброса своей авторизации:

```bash
sudo -k
```

Для отката удалить только `/etc/sudoers.d/90-lab-sudo-timeout` и снова проверить конфигурацию через `sudo visudo -cf /usr/etc/sudoers`.
